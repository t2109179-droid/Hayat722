# Hayat - Minimalist Müzik Deneyimi

Hayat, mobil öncelikli tasarlanmış, akıcı 3D tekerlek (wheel picker) arayüzüne ve glassmorphism detaylarına sahip minimalist bir web müzik çalar uygulamasıdır.

## Özellikler
- 📱 **Mobil & Dokunmatik Uyumlu:** Tam ekran, kaydırma kilitleri ve özel dokunmatik kontroller.
- 🎡 **3D Wheel Picker:** Sanatçı ve şarkı seçimlerinde şık tekerlek animasyonları.
- 🌐 **Canlı Ağ Durumu:** Çevrimiçi/Çevrimdışı durum algılama ve otomatik akış onarımı.
- 🎵 **Mini Player:** Şarkı değiştirebilme, durdurma/oynatma kontrolleri.

## Kullanılan Teknolojiler
- HTML5 / CSS3
- Tailwind CSS
- Vanilla JavaScript
